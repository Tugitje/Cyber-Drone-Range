# Baseline-resultaten

Per baseline een map `<datum>/` met de `samenvatting.txt`, `tcpdump.log` en de opname (`.pcap`) van elke run, plus een notitie met kloktijden en versies. Zie [Documentatie/baseline-procedure.md](../../Documentatie/baseline-procedure.md).

`scripts/run-vlucht.sh` en `tools/analysis/auto_vlucht.py` zetten de uitvoer per vlucht eerst in `results/vluchten/<naam>/`. Kopieer de runs die meetellen voor de baseline daarna naar deze map.
